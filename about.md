# Axtra's Utils

A Geometry Dash mod that disables visual effects, provides auto-click key simulation, and forces 16:9 aspect ratio.

## Features

- **Auto Click**: Simulate a key press at a configurable percentage of the level (useful for muting Discord, etc.)
  - Native Geode keybind setting (chords supported)
  - Works on Windows and macOS
  - Disabled on mobile (iOS/Android)
  - Automatically disabled when using start positions
- **No Orb Pulse**: Disables the pulsing effect on orbs
- **No Circles**: Disables all circle wave effects
- **Force 16:9**: Adds black letterbox bars to display the game in 16:9 aspect ratio

## Settings

All features can be toggled on/off in the mod settings menu in-game, accessible via the pause menu button.

If **Eclipse Menu** is installed, the same features are also available in an "Axtra's Utils" tab inside the Eclipse UI (both interfaces stay in sync). The pause menu settings button is then hidden, since the tab exposes the same toggles. The auto-click key stays a native Geode keybind, editable from the mod settings page.

## Platform Support

- **Windows**: Full support (auto-click + keybind)
- **macOS**: Full support (auto-click + keybind)
- **iOS/Android**: Visual effects only (auto-click unavailable)
